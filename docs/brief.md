# Desarrollo de Portafolio Profesional y Plataforma de Servicios Freelance

Quiero que desarrolles desde cero una **web profesional de portafolio y captación de clientes para un Full Stack Developer**, cuyo objetivo no sea únicamente mostrar mi experiencia, sino funcionar como una **vitrina comercial para ofrecer mis servicios de desarrollo de software y conseguir clientes freelance**.

La web debe transmitir que puedo desarrollar desde una página web sencilla para un profesional o emprendimiento hasta sistemas empresariales complejos, plataformas SaaS y automatizaciones.

## 1. Objetivo principal

La página debe conseguir que una persona que no necesariamente tenga conocimientos técnicos pueda entrar, entender rápidamente qué puedo hacer y tener una forma clara de solicitarme un proyecto.

El visitante puede ser:

* Un arquitecto que necesita una página web.
* Un restaurante que necesita un menú digital.
* Un emprendimiento que necesita una tienda online.
* Una empresa que necesita un sistema administrativo.
* Una empresa que tiene procesos manuales que quiere automatizar.
* Una persona que tiene una idea para una plataforma SaaS.
* Una empresa que necesita una API o integración.
* Alguien que simplemente tiene una idea y no sabe exactamente qué tecnología necesita.

Por lo tanto, la web debe vender **soluciones**, no únicamente tecnologías.

El mensaje central debe ser aproximadamente:

> **Desde una página web hasta una plataforma empresarial.**
>
> Desarrollo soluciones digitales a medida para profesionales, emprendimientos y empresas.

No quiero que la página parezca un CV tradicional.

Quiero que parezca una combinación entre:

* Portafolio profesional.
* Página de servicios.
* Landing page comercial.
* Casos de estudio.
* Perfil de desarrollador freelance.

# 9. Proyecto: Plataforma web para restaurante

Tengo participación como colaborador en el desarrollo de una plataforma web para un restaurante.

IMPORTANTE:

No presentarme como único creador si no corresponde.

Indicar claramente:

> "Proyecto desarrollado en colaboración."

La plataforma incluye:

### Menú digital

* Productos
* Categorías
* Información de productos
* Modificadores/personalización
* Carrito
* Generación de pedidos

### Pedidos

* Pedidos
* Domicilios
* Información del pedido
* Gestión desde panel administrativo

### Comunicación

El sistema NO tiene integración directa con WhatsApp ni con la API de Meta.

Lo que hace es:

* Facilitar la generación del mensaje del pedido.
* Redireccionar al cliente a WhatsApp.
* Permitir que el cliente envíe la información al restaurante.

No utilizar términos como:

> "Integración con WhatsApp"

cuando pueda interpretarse como una integración mediante API.

Utilizar:

> "Redirección a WhatsApp para facilitar el envío del pedido."

### Medios de pago

Actualmente no existe una pasarela de pago electrónico.

El sistema facilita:

* Copia de llaves de Nequi.
* Copia de números de cuenta bancaria.
* Visualización de información de medios de pago.

No presentar esto como un sistema de pagos.

### Panel administrativo

Debe destacarse especialmente:

* Gestión de productos
* Categorías
* Pedidos
* Domicilios
* Configuración
* Parametrización del sistema
* Información operacional

La plataforma está diseñada para que muchos aspectos puedan modificarse mediante parametrización.

### Impresión

Una característica técnica importante:

El sistema permite la conexión/sincronización con impresoras utilizadas para las comandas del restaurante.

Los pedidos pueden distribuirse a diferentes áreas y generar sus respectivas impresiones, por ejemplo:

* Cocina
* Caja
* Etiquetas
* Otras estaciones configuradas

Esto debe presentarse como:

> "Integración con el flujo de impresión de comandas del restaurante."

Esta funcionalidad es importante porque demuestra experiencia integrando software con procesos físicos/hardware.
